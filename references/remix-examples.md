# 用户认可的二创方法

后续新增清理规则优先于下面案例的全量保留要求：删除确认的水印、机构署名和软广，保留实质信息。案例一底部私信导流应删除，案例二免责声明保留，见 [content-cleanup.md](content-cleanup.md)。提示词使用清理后文案，并明确排除删除项。

2026-10-10，用户认可下面两种实际生图结果，要求后续沿用此思路：参考原图的信息组织框架，设计明显不同的新视觉。完整内容、严格3:4与整组统一是共同约束。

## 案例一：留学生实习岗位清单

原图为橙色渐变、橙色大标题、胶囊副标题、白色大面板、橙色弧形企业标签。

保留：顶部标题/副标题 → 京东、拼多多、理想汽车、蔚来汽车四块 → 每块完整特点优势、岗位方向、适合人群 → 底部沟通文案。重复的毕业条件逐项保留。

重做：暖米白纸质背景、墨绿文字、珊瑚橙强调；标题左对齐，右上原创成长阶梯插画；四个独立细边框卡片，企业名左对齐，左侧窄强调线，字段小标记。改变颜色、字形、标签、卡片与装饰，保留实用清单结构。

用户在看到近似原图的橙色版本后明确“要和他们的有区别，大概的框架可以参考原图”。因此参考原图不是复制它的视觉。

## 案例二：适合留学生的外企地区清单

原图为城市日落摄影、深红背景、厚描边大字、黄色胶囊标签、圆形国旗、三个地区模块。

保留：顶部“仅为信息分享，不涉及招聘” → 主标题及三个优势短语 → 日本、英国、北欧三块 → 每块完整描述、代表企业名单、适合方向。免责声明不可删。

重做：浅蓝纸纹、深海军蓝标题、少量柠檬黄强调；原创地图航线替换城市摄影；方形旗帜配地区名；白色细边框卡片；富士山樱花、伦敦地标、北欧山林房屋插画统一画风。插画辅助识别地区，不挡字，不加入新招聘结论。

## 执行与提示词

新增提示语按 [disclaimer.md](disclaimer.md) 逐张判断：具体求职推荐页需加，通用方法页不默认新增，原图必要声明保留。删除导流与提示语判定分别进行。

先看原图并冻结完整文字，再为整条链接选择一套新规范。方法可迁移，颜色和插画按主题重新选择，不机械重复两个案例。同组每张只替换对应内容与必要的插画主题，配色、字形和卡片语言不变。

```text
根据参考图二创一张严格3:4竖版中文信息图。
参考图仅用于内容和大致信息框架：{原图标题/模块/字段结构}。
重新设计视觉，让成品明显区别于原图。
本组统一设计规范：{背景、配色、字体、标题、卡片、插画、边距}。
替换原图的：{至少三项具体视觉元素}。
全部图片复用本组规范；插画不遮挡正文。
逐张依据disclaimer_decision生成：required=true时在底部安全留白加入可读小号提示语“仅作信息分享 不涉及任何招聘”，逐字准确，不遮挡、不溢出；false时不新增，保留原图必要声明。
以下为必须逐字完整呈现的冻结文案：
{本张完整标题、副标题、模块描述、全部字段、重复条件、底部小字/免责声明}
保持顺序、名称、数字、条件不变，不新增未经验证的事实。
不能删字、概括描述、省略企业或重复条件。
```

回看实际结果，核对文字、数量、可读性、比例、整组一致及与原图区别。发现问题先纠正，不以模型返回成功代替验收。生图不提供脚本DOM校验，记录真实视觉核对与尺寸；固定文字脚本可作为备用和纠错方式，内置模板不等于这两次生图设计。
