# 微信贴图号配文

默认共用selection.json与content.selected_indices的最终选图范围。整组分析不构成正文材料；未选页任何具体事实不得混入配文。选图变更后重写配文，检查每项信息对应所选页。

输入链接 → 看图提取 → 精准清理 → 二创并验收 → 自动输出一段200字以内的配文。用户明确不要配文时省略；默认另输出580–620字正文及3个标题。

配文由宿主实际模型创作，基于本次已交付图片的清理后文案，不依赖假设配置的外部API。只输出一段可直接复制的正文，保存caption.txt；无独立标题、列表或默认话题标签。

## 内容要求

- 开头交代具体对象或读者问题，中间提炼图片的主要价值，结尾可给一个与内容有关的实际建议。自然简洁，不机械复述整张图。
- 贴合实际输出范围：只生成前两张就写前两张的信息，不把未交付的考试科目、岗位清单等说成图中已有。
- 不新增薪资、时间、资格、企业名单、政策、成功案例或招聘承诺。图片中的时效性资料未查证时用“图中资料”“整理了”等来源表达，不写“正在招聘”“今天截止”等实时断言。
- 不把某一岗位适用条件说成全体岗位通用。例如“2026届可投补录”不能写成“2026届全部可报名”。有必要的例外仍准确表述。
- 与清理规则一致：不带回机构推广、二维码、微信号、私信咨询、购买课程等软广。不使用诱导点赞转发、保证推荐或夸张效果承诺。
- 200字限制适用于配文正文。保存后实际统计，按Unicode字符保守计数，标点、数字、英文均计入，空白与换行不计入；超出就改写配文，不删减图片内容。优先约80–160字，但不为凑字数重复。

## 验收

逐句对照实际图片：对象、日期、条件与例外正确，内容范围吻合，无新增事实与广告。检查是一段且长度≤200，在核对记录标明字数。用户看到的是完整正文，计数和内部说明放在交付说明中。

可用Python检查实际文件：

```text
python -c "from pathlib import Path; s=Path('任务目录/caption.txt').read_text(encoding='utf-8').strip(); assert s and sum(not c.isspace() for c in s)<=200 and '\n' not in s; print(sum(not c.isspace() for c in s))"
```
