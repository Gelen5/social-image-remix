# 选图与连贯性

选图决定可使用的原图范围；智能重组在该范围内决定成品结构与页数，两者不同。smart允许合并重复信息和重新组织，不能扩大范围或丢失独有事实；参见 [smart-reorganization.md](smart-reorganization.md)。

## 三种入口

- 用户明确指定“第2张、第3张”：直接采用原图页码[2,3]，先检查上下文，选择范围不需要重复确认。默认按原图顺序输出，不自行扩成全部。
- 用户问“哪些可以选、不影响连贯性”：先读完整组，给选图方案；没有最终选择前不生成图片。若用户明确授权“你帮我选并做”，可据分析选择、说明理由后继续。
- 只输入链接、没有范围或选图诉求：默认完整图集。用户只要一张、但未说明哪张时，可推荐并请求选择，独立进行整组分析。

页码从1开始，以原作品图集顺序为准，与截图下载顺序、输出文件名区分。重复提到同一页去重；不存在的页码报出总数，请用户更正，不猜、不替换。

## 分析标准

逐页记录主题、核心事实、角色（封面/定义/步骤/案例/结论）、前置依赖与独立可读性。检查：跨页表格或句子；步骤缺失；“上述/因此/这一类”等指代；只有结论缺少依据；封面标题与所选正文不匹配。

给2–3个有实际依据的方案即可；每个写原图页码、组合主题、为何连贯、缺失上下文或风险、适合的配文/文章方向。不要对同一篇所有组合机械评分或承诺推荐量。没有完整图集就说明无法判断整组，不编造其他页。

所选页可独立理解就继续；小的衔接问题可用所选页已明确的信息调整换行或标题呈现，不新增事实、不删实质信息。关键定义、条件或步骤只在未选页时，提示需要补选的具体页及理由，等待用户决定；不可擅自把那页内容补到图或文章中。

## 范围记录

selection-analysis.md记录整组分析和建议；selection.json示例：

```json
{
  "total_images": 5,
  "selected_indices": [2, 3],
  "basis": "user_specified",
  "coherence_status": "pass",
  "dependencies": [],
  "reason": "两页共同完整介绍同一主题"
}
```

这是格式示例，不是对任意第2、3页的预设判断。需要确认时coherence_status为needs_confirmation，不标记通过。

完整manifest保持5张；content.json的selected_indices=[2,3]，cards仅含对应原图。输出01.png、02.png分别映射原图第2、3张，在交付和核对报告中明确，不让客户误认为原图第1、2张。同一链接后续追加页沿用已选设计规范；脚本备用路径显式传已有模板，不因改变范围随机换风格。

图片、200字内配文、长文章共用选定范围：不得提取未选页的企业、条件、时间、结论等事实进入成品。文章可以组织论述，不能为连贯偷偷补入未选页；逐项核对所选页来源，新增查证事实需用户另行授权扩展范围。
