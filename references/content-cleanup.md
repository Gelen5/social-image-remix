# 水印、机构署名与软广精准清理

用户明确要求二创时准确删除图中的水印、机构名和软广。这是完整保留信息的授权例外：保留实质信息，清理确认的署名、宣传和导流。

## 判定边界

删除可确认的制作/发布机构署名、账号昵称、平台水印、机构Logo、宣传口号，以及用于引流的二维码、电话、微信号、网址、私信提示、咨询报名、课程售卖、优惠和服务推销。

机构名称按角色判断：求职辅导机构作为“出品/咨询/报名”署名应删除；京东、拼多多、联合利华等作为本文介绍的企业不能删除。研究机构、数据发布方、法定主体、必要来源或资质属于内容依据时保留。不能仅因名字像公司就删除。

免责声明、适用条件、日期、单位、表格注释、必要事实来源默认保留。例如“仅为信息分享，不涉及招聘”不可误删。不能将清理署名表述为资料由自己原创或已独立核验。

企业特点、产品参数和岗位说明不自动等于软广。只删可定位的推销/导流片段；广告混在正文同句时做最小片段删除，保留其余信息，不概括整段、不补编事实。无法确定是广告还是关键事实时，标记疑点并请求确认，暂停该删除，不把猜测记为准确判断。

## 可复核流程

1. 下载原图与manifest不变。全部文字先转录到source-content.json，图片型Logo和二维码记录位置。
2. 每项删除写入removals.json，列出源图、原文或视觉描述、位置、类别、理由和处理方式。没有删除项时写空数组。
3. 清理后的保留文案写入content.json。已确认纯广告footer可置空；混合底部仅删广告片段，免责声明保留。
4. 对照原图、原始转录和删除清单：每处变化有理由，其他文字、数字、条件和顺序未丢失，再设置transcription_reviewed=true。
5. 生图提示词附清理后的完整文案，并明确排除对应水印、Logo、署名、二维码及软广。插图也要核查，不把带广告的裁块重新嵌入。
6. 查看成品确认删除项无残留、重现，保留信息完整；在transcription-review.md记录结果。脚本没有自动OCR或广告检测能力。

水印覆盖正文时重新排版恢复可辨文字，不裁掉整块正文；无法辨识的关键内容先确认。

removals.json格式示例：

```json
{
  "items": [
    {
      "source_image": "01.webp",
      "original": "留学生专属1v1私信沟通",
      "location": "底部",
      "category": "导流软广",
      "reason": "引导私信咨询，与岗位清单事实无关",
      "action": "删除导流文案，保留企业信息与毕业条件"
    }
  ]
}
```

已认可的两次案例用于学习框架和新视觉；按本次新规则执行时，实习清单底部“留学生专属1v1私信沟通”应删除，外企清单的免责声明仍保留。清理适用于二创图片与配套文章，不删除本地来源审计记录。
