# 二创图片交付前质量检查

每张最终图片都要实际打开检查，不能只检查第一张，也不能只看缩略图、提示词或工具返回成功。

## 文字

逐块对照原图、content.json及删除清单，检查标题、企业/人名、全部描述、字段、列表、数字、年份、范围符号、单位、标点、英文和必要免责声明。确认无新增错别字、漏字、多字、乱码、同音字替换、重复或顺序错误；导流广告已删除且未重新生成。

原图本身可能有错字。明确可确定且不改变事实的笔误可更正，同时记录原文与更正原因；涉及专名、数值、含义不明的缩写或原图不清时，请求确认，不猜测、不把存疑内容标为准确。遵循原始转录和修订记录，不静默改写事实。

## 排版

检查实际画布比例3:4；全文在画布与卡片范围内，没有溢出、裁切、重叠、装饰/插画遮挡；行距、内边距和换行合理，标题层级清楚。按手机正常阅读尺寸检查，不以放大后勉强能读作为通过。正文过密时调标题占比、装饰、间距和字号，但不能删信息；仍放不下时请求确认分页。整组配色、字体和卡片语言一致。

## 修正与记录

发现问题先记录具体页、文字或位置，再针对性修正或重生成；查看新文件并重新检查该页。每次修改都更新哈希与核对记录。未解决问题不得交付，也不得为了通过将issues设空。

text-review.json增加image_checks数组，覆盖全部本次输出，顺序与图片报告相同：

```json
{
  "image_checks": [
    {
      "file": "01.png",
      "source_index": 2,
      "sha256": "最终输出图片的实际哈希",
      "text_correct": true,
      "layout_passed": true,
      "issues": [],
      "notes": "实际逐块文字、数字、边缘及手机阅读检查结果"
    }
  ]
}
```

以上为格式示例，不能替代真实检查。check_delivery.py阻断漏检、未通过、未解决问题、输出版本不一致；它验证宿主核对记录，不提供自动OCR或视觉排版判断。固定渲染的DOM/溢出检测可辅助，但不替代对最终PNG的检查。
