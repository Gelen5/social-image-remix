# 成品模板列表（红黑 / 橙黑配色体系）

本目录存放已定稿、可直接复用的**成品模板**，与 `references/themes/` 的主题组件库并行：
主题库 = 排版引擎按内容现场装配；**本目录 = 已装配好的成品，直接取用或微调**。

## 模板清单

| 模板 | 文件 | 类型 | 用途 |
|------|------|------|------|
| 红黑配色模板 | `配色模板_红黑(red-black).html` | 完整 HTML 页面 | 设计规范参考：标题层级、正文、按钮、链接、页脚的红黑全套样式（含 CSS 变量定义） |
| 橙黑配色模板 | `配色模板_橙黑(orange-black).html` | 完整 HTML 页面 | 同上，橙黑版（强调色 `#E67E17`） |
| 红黑样文正文 | `样文正文_红黑版(red-black).html` | 公众号可粘贴纯 `<section>` 片段 | 备考经验帖/干货文成品样文，红色 `#C00000` 标注每节核心方法；`*_预览.html` 为带「复制到公众号」按钮的预览页 |
| 橙黑样文正文 | `样文正文_橙黑版(orange-black).html` | 公众号可粘贴纯 `<section>` 片段 | 同一篇正文换橙黑强调，供对比选择 |

> 样文正文是**不含标题的正文片段**——外标题按下方硬规则单独交付。配色模板含 CSS 变量与完整页面结构，用于设计参考或网页场景，**不要直接整页粘贴进公众号编辑器**；粘贴公众号一律用样文正文这类纯 `<section>` 片段。

## ⛔ 硬规则（任何模板/文章都不得违反）

1. **外标题不写入正文**：文章外标题绝不放进正文 HTML（不进产物、不进正文第一行），交付时**单独输出给用户**（一条消息只给标题）。外标题 14–22 字，≤28 字为上限。
2. **单篇配色 ≤2 色**：正文黑 `#000000` 16px / 行高 2.0；加粗强调色红 `#C00000` **或** 橙 `#E67E17` 二选一，**红橙不得混用同一篇**。
3. **加粗规范**：加粗是唯一的强调手段；密度控制在全文 10–15%，单块 ≤15 字；红色加粗 = 每节唯一核心方法（全文 ≤4 处），黑色加粗 = 关键信息/数据。
   > **段落锚点原则（修正"每段必加粗"）**：锚点的目的是让"扫读"能抓住每段干货，但**切忌机械地每段都塞一个加粗**——处处都亮会让视觉脱敏、重点全失效。正确的判据是看段落作用：
   > - **干货信息段**（误区/方法/结论/数据）：**必须有锚点**（红或黑），否则整段会被扫读直接跳过，信息流失。绝大多数正文段属此类，应默认配锚。
   > - **纯过渡 / 情绪收束的短段**（承上启下、篇幅 1 句内、无独立干货）：**可豁免不加粗**，作用是给眼睛喘息、并让真正重点的凸起更突出。
   > - **小标题行**天然是锚点，行内无需再加粗。
   > 成稿后自查一遍：若某"干货段"通篇无锚 → 补；若某"过渡短段"硬凑加粗显得别扭 → 删。加粗要有轻有重，读者只扫锚点即可把握全文，又不至于被一整屏的粗体淹没。
4. **括号补充层**：`（…）`解释性内容字号 14px、色 `#767676`、左侧 2px 灰竖条 + 12px 缩进，视觉上与正文分层。
5. **粘贴兼容**：公众号产物全部内联样式、背景一律 `background-color` 实色（禁 `background:` 简写与渐变）、文字节点全部 `<span leaf="">` 包裹、产物为纯 `<section>` 片段。
6. **正文字数 ≤800 字**（用户标准）：单篇只讲透一个核心方法，内容多拆系列篇；价值前置，开头三行直接给利益点。
7. **正文两端缩进 = 0（不写左右内缩）**：正文段落一律 `margin:0 0 Npx` + 无 `padding-left/right`，文字**顶满内容区左右边界**。公众号正文内容区本身自带约 15px 系统留白，叠 8px 之类小内缩既"看不出变化"又挤窄每行（负优化），故正文自身左右内缩固定归零；留白由 系统边距 + 行距 2.0 + 段间距 三级承担。
   > **例外（非正文块才允许内缩）**：仅"降级注释层"（`（…）`括号旁白，14px/灰）与"引用/独立说明块"可加 `padding-left` ≥12px（搭配灰竖条），目的是把它**压到正文下一级**；小标题、正文句一律不内缩。
   > 一句话：**正文左右缩进 0，特殊降级块才有 12px+ 内缩**。不要对整段正文叠加无谓内缩。

## 取用方式

- 直接交付：复制对应样文/模板文件 → 用户已确认的微调 → `python3 scripts/validate_gzh_html.py` 校验 0 ERROR → `python3 scripts/wrap_preview.py` 出预览页 → 交付（标题单独发）。
- 换强调色：红黑 ↔ 橙黑只需把 `#C00000` 全局替换为 `#E67E17`（或反向），不得再引入第三种颜色。
