# 按最终图片语义决定提示语

本规则替代旧版“每张图片无条件添加”的要求。宿主在清理广告、完成选图和智能重组后，逐张阅读最终保留内容并决定是否新增“仅作信息分享 不涉及任何招聘”。不按整条链接统一判断，不仅凭关键词命中判断。

- recruitment：以求职为语境介绍或推荐具体企业、具体岗位、招聘/校招/实习计划，或给出申请条件、投递窗口等信息，必须加。企业适合人群、企业清单和岗位方向推荐，即使没有投递入口，也属于此类。
- general：通用简历、面试、职业方法等，不包含具体招聘推荐，不新增。企业名称仅出现在产品介绍、历史说明、业务案例中，且不构成求职推荐，也不新增。
- uncertain：语境不清但可能被理解为具体招聘推荐，保守添加，reason中明确不确定点。疑字或事实不明仍按原有核对规则处理，提示语不能代替事实核验。

判定只依据本张最终保留的信息。未选页、删除的软广或同组另一页不能成为触发依据。重组后每张重新判断，例如公司清单页需加、合并后的通用面试方法页可不加。原图必要免责声明必须保留，不因general而删除；仅完全相同的固定声明可以去重，其他限定信息不能覆盖。

每个content.cards条目新增必填disclaimer_decision，冻结后和其他内容一同参与哈希：

```json
{"required":true,"classification":"recruitment","reason":"介绍具体企业的实习岗位和届次条件","evidence":["岗位方向：研发、产品、运营","2027届及以后毕业"]}
```

general使用required=false；uncertain使用true。reason是非空语义理由，evidence为非空字符串数组，引用本张保留内容。通用内容也需记录实际依据，如“简历中如何描述项目经历”。这些是宿主实际分析记录，脚本只核验结构及一致性，不自动理解截图或判断推荐语境。旧任务缺少判断字段时需补做分析，不能默认全部添加或自动套general。

生图提示词逐张传入判断：required=true时准确加入固定提示语；false时不新增，仍保留必要原有声明。提示语放在安全留白内，约22px/1080px宽，底部边距至少24px，清晰且不遮挡、不溢出，不删正文腾位置。同组字体、颜色和位置规则保持一致，未加提示语的页面不用虚构补充文字。

图片报告cards每项记录disclaimer_decision（与当前content完全一致）和disclaimer：新增时为完整固定文案，不新增时为JSON null。null仅代表未新增，不代表原图已有声明被删除。逐图实际检查判断依据、应加则实际字形/位置、原有必要声明保留；通过后image_checks.disclaimer_reviewed=true，notes写核对依据。不应加却新增、应加缺字、旧判断、漏看成品均需修正后再交付。报告不能代替真实看图。
